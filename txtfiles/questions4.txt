What is the difference between an unordered (<ul>) and an ordered (<ol>) list, and when would you use each?
An unordered list is a list with bullets while an ordered list is numbered 1, 2, 3 etc. An unordered list is
useful for general stuff while an ordered list is useful when the order of the list matters.

Why is a relative link the right choice for a page on your own server, and when must you use a full absolute URL
(starting with https://)? (In ../ic3/ic3.html, what does .. mean?)
A relative link is the right choice for a page on your server because it only has to redirect itself up the
files, and an absolute link is needed when linking a webpage outside of your server.

What is alt text on an image for, and who benefits from it?
The alt text is for screen readers and to describe the image even if it fails to load.

What does it mean that images/favorite.jpg is a relative path?
It means that it's on your server files, so it looks for the path inside the direction you set it to.
